# Mathemzi Edu

Premium mathematics learning platform built with Vite, React, Tailwind CSS, Firebase Auth, and Firestore.

## Local Setup

1. Install dependencies:
   `npm install`
2. Configure Firebase in `firebase-applet-config.json`.
3. Run the app:
   `npm run dev`

## Checks

- TypeScript: `npm run lint`
- Production build: `npm run build`

## Notes Before Launch

- Deploy updated `firestore.rules`.
- Configure real payment/enrollment automation before accepting live course or exam fees.
- Replace placeholder social/contact links with official brand accounts.
